## 后续更新对话

项目提供 scripts/export-conversation.ps1。传入当前会话对应的本机 JSONL 文件，可更新本次归档；它只提取用户/助手文字，不复制原始会话中的系统指令、内部推理、工具日志和账户信息。

```powershell
./scripts/export-conversation.ps1 -SessionFile '本机当前会话文件的绝对路径.jsonl'
git add 对话
git commit -m "Update conversation archive"
git push origin main
```

此脚本固定更新本次 2026-10-26 会话归档；其他会话应另设文件名，避免覆盖。本次导出之后的新消息不会自动进入备份。
