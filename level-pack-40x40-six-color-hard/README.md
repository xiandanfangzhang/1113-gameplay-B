# 六色 40×40 九关加强版

`level-01.json` 至 `level-09.json` 是九个独立的 version 5 单关文件，可直接导入现有 Demo。本目录是回应“整体提升难度”后的新交付；旧版仍在相邻 `level-pack-40x40-six-color/`，不会替换 Demo 内置关卡。

每关使用红蓝黄绿橙紫六色、40×40 满铺 1600 球、六道路车位。每车容量均为 10 的倍数，逐色球数和车辆容量完全相等。没有修改玩法或使用未确认的梯形补位。

## 导入与试玩

1. 在 `color-transit-demo` 目录运行 `node scripts/dev-server.mjs`，浏览器打开 `http://127.0.0.1:4173/`。
2. 打开“关卡编辑器”，选一个关卡槽位；在“保存与试玩”内展开“导入 JSON”，选择本目录的 `level-XX.json`，点击“导入到当前关卡”。导入器会把文件 ID 映射到当前槽位。九关须逐个导入；若槽位内有需保留的草稿，先导出备份。
3. 点击“即时试玩”。界面有当前模拟步数；`SOLUTIONS.md` 列出每辆车的 ID、所在列和准确派车步数，未列出的步数等待。为检查复现，留意表中的派车前路车数、剩球数和底排可接色。
4. 返回编辑器点击“保存到本机”可保留当前关卡。保存位置是当前浏览器的本地存储。

## 自动复核

在 Demo 根目录运行：

```powershell
node level-pack-40x40-six-color-hard/replay-pack.mjs
```

脚本直接读取九个最终 JSON，通过现有导入器、校验器和正式玩法引擎，逐关重放两条无道具通关路线及六条代表性替代分支。`verification-report.json` 保存完整逐车操作、球数、车库配置、终局、峰值和分支结果；`DESIGN.md` 解释难度设计与证据边界。

关卡难度尚未经过真人试玩标定。尤其相邻中段关卡的主观先后仍需试玩调整。
