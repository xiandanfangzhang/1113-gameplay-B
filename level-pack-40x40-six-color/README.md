# 六色 40×40 九关包

`level-01.json` 至 `level-09.json` 是九个独立的 version 5 单关文件。它们使用 Demo 当前支持的红、蓝、黄、绿、橙、紫六色，不替换原有三个内置关卡。上一版四色关卡仍在相邻的 `level-pack-40x40/`，本目录为本次重新制作的六色交付版。

## 导入与试玩

1. 在 `color-transit-demo` 目录执行 `node scripts/dev-server.mjs`，浏览器打开 `http://127.0.0.1:4173/`。
2. 进入“关卡编辑器”，选一个当前关卡槽位；在“保存与试玩”展开“导入 JSON”，选择本目录的某个 `level-XX.json`，点击“导入到当前关卡”。导入器会把文件 ID 映射到所选槽位。九关须逐个导入试玩；导入前请先导出需要保留的编辑草稿。
3. 查看编辑器中的六色球数与运力统计，点击“即时试玩”。参照 `SOLUTIONS.md` 的车辆 ID、列、派车顺序、模拟步数和派车前道路占位。建议用 1× 速度；手动错过精确步数时可重开，结果可能因时序变化而不同。
4. 要在当前浏览器保留该关，返回编辑器后点“保存到本机”。浏览器本地存档只适用于当前浏览器和来源。

## 复核

在 Demo 根目录执行：

```powershell
node level-pack-40x40-six-color/replay-pack.mjs
```

脚本直接读取最终 JSON，用现有导入器和正式玩法引擎检查结构、六色、40×40 满铺、道路 6 车位、单车容量为 10 的倍数、逐色运力，以及每关两条无道具完整通关路线。它还重放两组各三条代表性替代派车分支。`verification-report.json` 保存车辆配置、种子、路线、峰值与分支终局；`DESIGN.md` 说明递进意图和证据限制。`candidate.mjs` 是可复现的候选构造来源，`branch-scan.mjs` 用于补查后段列优先分支。

难度排序尚未经玩家测试；相邻关的真实感受仍需人工试玩校准。
