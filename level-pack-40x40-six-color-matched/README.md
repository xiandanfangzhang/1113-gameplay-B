# 六色九关：按四色参考包的难度节奏设计

`level-01.json` 至 `level-09.json` 是九个独立的 version 5 单关文件，可导入现有 Demo。本包以相邻的 `level-pack-40x40/` 四色九关为难度参考：前两关容错高，中间四关开始有明确错误分支，末三关要求更谨慎地管理道路车位。此前的六色普通版与加强版继续保留，本目录是本次指定难度的交付版。

每关 40×40 满铺 1600 球，使用红蓝黄绿橙紫六色，道路上限 6，车库三列。车辆容量均为 10 的倍数且逐色运力精确匹配球数。没有改变 Demo 核心玩法或使用梯形补位。

## 导入与试玩

1. 在 `color-transit-demo` 目录运行 `node scripts/dev-server.mjs`，浏览器打开 `http://127.0.0.1:4173/`。
2. 进入“关卡编辑器”，选择当前关卡槽位；在“保存与试玩”中展开“导入 JSON”，选择本目录的一个 `level-XX.json`，点击“导入到当前关卡”。九关须逐个导入。导入会替换该槽位的编辑草稿；需要保留草稿时先导出。
3. 点击“即时试玩”。顶部显示模拟步数；按 `SOLUTIONS.md` 对应关卡的车辆 ID、所在列与步数派车。未列出的步数等待。派车前路车数、剩球数和底排可接色可用于核对局面。错过精确时点后可重开再试。
4. 返回编辑器后点击“保存到本机”，可在当前浏览器与来源下保留已导入关卡。

## 自动复核

在 Demo 根目录运行：

```powershell
node level-pack-40x40-six-color-matched/replay-pack.mjs
```

脚本直接导入最终九个 JSON，用 Demo 正式引擎逐步重放每关两条无道具通关路线和三种固定列优先分支，并检查六色、40×40 满铺、逐色运力、容量、道路六车位、接球数和真实过关条件。`verification-report.json` 保存可复现的全部操作与分支终局；`DESIGN.md` 对比四色参考包的容错梯度；`build-candidates.mjs` 保存候选构造过程。

难度对齐依据是结构与被测分支，尚未经过真人玩家试玩校准。
